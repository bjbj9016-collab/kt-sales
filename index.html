🔑 API 키 설정 방법

    

      드라이브 조회용 API 키

      1. console.cloud.google.com → 사용자 인증 정보

      2. API 키 생성 → Google Drive API 제한 적용

      3. 개통 폴더 → 공유 → 링크 있는 사용자 권한 설정

      4. 생성된 API 키를 위에 붙여넣기
